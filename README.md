# U duhu svetinje — novi dizajn za GitHub Pages

Potpuni statički portal: 7 HTML stranica, CSS, JavaScript, podaci za pretragu i 45 optimizovanih WebP fotografija. U ZIP-u **nema originalnih duplikata fotografija niti razvojnih Python skripti**. Tekst i opisi preneseni su iz dostavljenog Word dokumenta bez redakcije.

## Postavljanje na GitHub Pages

1. Otvorite novi GitHub repozitorijum.
2. Otpremite **sav sadržaj ovog foldera** u korijen repozitorijuma: `index.html`, ostale `.html` stranice, `assets/`, `data/` i `README.md`.
3. U GitHub repozitorijumu otvorite **Settings → Pages → Deploy from a branch → main → / (root) → Save**.
4. Sajt se otvara na GitHub Pages URL-u repozitorijuma. Ne treba Python, Node.js niti baza podataka.

## Fotografije

Sajt koristi samo datoteke `assets/photos/foto-001.webp` do `foto-045.webp`. Fotografije su izvodi iz originalnog Word dokumenta. Originalni izvori nijesu uključeni u ZIP radi manje veličine. Za eventualnu arhivsku restauraciju čuvajte izvorni Word dokument zasebno.

## Izmjene

Boje i raspored: `assets/site.css`. Interakcije: `assets/site.js`. Sadržaj je upisan direktno u HTML, a `data/search-index.json` omogućava pretragu.

## Napomena

Arhivski tekst i potpisi preneseni su bez promjene izvornih formulacija. Prije javne objave provjerite autorska prava na fotografije, uredničku odgovornost i prikaz na mobilnom uređaju.
